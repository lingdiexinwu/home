## 更换首页视频

将经授权的 MP4 视频放在 `assets/hero.mp4`，封面图片放在 `assets/hero-poster.jpg`。视频默认自动播放、静音、循环，并使用 `playsinline` 支持手机内嵌播放。视频未上传或播放失败时，会展示渐变动态背景。建议压缩视频文件，并测试手机端加载表现。

## 发布

在 GitHub 仓库 Settings → Pages 中选择 Deploy from a branch，分支 `main`，目录 `/ (root)`。发布后通常可通过 `https://lingdiexinwu.github.io/home/` 访问（以 GitHub Pages 显示的实际地址为准）。
